## 📊 Технічні Деталі

### Порядок Рендерингу

```javascript
// beforeRender - портали (нижній шар)
Matter.Events.on(render, 'beforeRender', () => {
  currentTrack.obstacles.forEach(obs => {
    if (obs.obstacle.renderPortals) {
      obs.obstacle.renderPortals(ctx);
    }
  });
});

// Matter.js render - трикутники та bodies

// afterRender - ефекти (верхній шар)
Matter.Events.on(render, 'afterRender', () => {
  // trails, glow, particles, корона лідера
});
```
